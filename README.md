# Curso: Armazenando dados de um E-Commerce na Cloud

### Projeto prático ensinando como:

- Criar um banco de dados SQL Server na Cloud Azure
- Criar um Storage Account para upload e armazenamento de imagens
- Utilizar o streamlit do python para criar um formulário 
- Através do Formulário podemos fazer upload da imagem através do Blob Storage e salvar dos dados de uma entidade Produto no Banco de dados da cloud
